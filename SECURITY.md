# Security Policy

## Supported versions

Only the latest release of ChordMate receives fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems (for example a crafted session or MIDI file that
crashes the host or corrupts memory).

Report it privately through GitHub's
[private vulnerability reporting](https://github.com/ravaninip/ChordMate/security/advisories/new).
Include the steps to reproduce and, if possible, a sample file.
You will get an answer within a week.
